# 运行手册

## 1. 环境

本项目已在 Python 3.13、Windows PowerShell 下执行验证。核心依赖是 NumPy、SciPy、scikit-learn、PyTorch、Matplotlib 和 pytest。

```powershell
cd C:\Users\18562\Documents\ChatGPT\3d
python -m pip install -r requirements.txt
python -m pytest -q
```

若企业环境不允许直接安装，可使用现有虚拟环境的等价包；不建议在一个项目中混用多个 Python 解释器安装依赖。

项目调用现成几何库的方式：

```powershell
# Open3D Python 后端
python -m pip install -r requirements-open3d.txt

# PCL 是 C++ 库，需要用 CMake 构建 cpp/ 下的程序
# Windows/vcpkg、conda-forge 和 Linux 安装方式见：
# docs\库后端与代码流程说明.md
```

本项目保留三种传统处理实现：

- 默认 NumPy/SciPy/scikit-learn 实现：无需 Open3D/PCL，便于阅读和调试。
- Open3D 后端：推荐作为 Python 研究基线。
- PCL C++ 后端：适合产线侧、大点云和 C++ 集成。

## 2. 合成工位全流程

```powershell
python -m industrial_pc3d.cli demo --output outputs\demo
```

默认场景包含：

- 大工装平面；
- 远处背景点；
- 两个不同尺寸、不同偏航角的工件；
- 传感器高斯噪声；
- 目标工位 `target_xy=[0.42, 0.0]`。

主要输出：

| 文件 | 含义 |
|---|---|
| `scene_raw.pcd` | 原始场景 |
| `scene_roi_denoised.pcd` | ROI 内下采样并去噪的点 |
| `parts_without_plane.pcd` | 移除基准平面后的工件候选 |
| `target.pcd` | 按目标位置选中的工件 |
| `target_edges.npz` | 边缘点 |
| `target_analysis.npz` | 目标坐标、局部变化量和二值边缘分数 |
| `pipeline_preview.png` | 三阶段预览 |
| `run_summary.json` | 点数、耗时、平面、簇、OBB/AABB |

## 3. 处理自己的点云

```powershell
python -m industrial_pc3d.cli process `
  --input data\scan_001.pcd `
  --config configs\traditional.json `
  --output outputs\scan_001
```

支持 `.pcd` 的 ASCII/binary 未压缩格式，`.ply` 的 ASCII 顶点格式，以及 `.xyz`、`.csv`、`.npy`、`.npz`。专有传感器格式和 PCD `binary_compressed` 建议先在原厂 SDK、PCL 或 Open3D 中转为普通 PCD。

### 配置说明

| 参数 | 作用 | 调整建议 |
|---|---|---|
| `roi_min/roi_max` | 粗 ROI 下上界 | 先可视化场景，按工位坐标系设置 |
| `voxel_size` | 下采样体素 | 约为目标最小缺陷尺度的一半，同时满足节拍 |
| `sor_k/sor_std_ratio` | 统计去噪 | 点少时减小 `k`；高反光区域可分区处理 |
| `radius_nb_points/radius` | 半径去噪 | 设为 0 可关闭；按实际点密度设置 |
| `ransac_distance` | 平面内点距离 | 通常略大于扫描噪声和平面度误差 |
| `ransac_iterations` | 平面采样次数 | 内点占比较高时 100–500 已足够 |
| `cluster_eps` | DBSCAN 邻域半径 | 至少大于下采样点间距，但小于工件间距 |
| `cluster_min_samples` | 最低局部密度 | 与 `eps` 联动；过大会切碎工件 |
| `cluster_min_points` | 全簇最低点数 | 过滤工件边缘碎片；过大会漏掉小工件 |
| `target_xy` | 目标工件平面位置 | 不设则选最大簇 |
| `normal_k` | 法线邻域点数 | 应覆盖局部形体，不宜跨边界面 |
| `edge_quantile` | 曲率边缘分位 | 越大边缘越少 |
| `boundary_angle_deg` | 边界角间隙 | 扫描边界多时较敏感 |
| `obb_margin` | OBB 裁剪余量 | 用于去掉残余离群点，不要切掉真实边缘 |

所有长度单位必须一致。如果 `scan.pcd` 单位是毫米，体素、ROI、平面距离、聚类半径和 OBB 余量也必须使用毫米。

## 4. 模板配准

合成验证：

```powershell
python -m industrial_pc3d.cli registration-demo --output outputs\registration_demo
```

保存的 `source_aligned.pcd` 是源点云变换到目标模板坐标系后的结果，`transform_4x4.npy` 可用于后续 CAD 比较或机器人坐标转换。

真实点云：

```powershell
python -m industrial_pc3d.cli align `
  --source data\scan_001.pcd `
  --target data\template.pcd `
  --output outputs\alignment_001 `
  --voxel-size 0.015 `
  --icp-distance 0.03
```

调参顺序：

1. 检查源/模板单位、法向方向和初始粗略位置。
2. 看 `global.feature_matches`、`fitness` 是否足以提供正确粗位姿。
3. 调整 `voxel_size` 和 ICP 距离，不要一开始用过大的距离阈值。
4. 对长方体、圆柱等对称物体增加参考孔、标记或非对称裁剪区域。
5. 用独立样本统计配准失败率，不要只看一个案例的 `fitness`。

当前实现为点到点 ICP。工业高精度场景可在 Open3D/PCL 中换成点到面 ICP，并增加法向、鲁棒核和多尺度配准。

Open3D 配准入口：

```powershell
python -m industrial_pc3d.cli align-open3d `
  --source data\scan_001.pcd `
  --target data\template.pcd `
  --output outputs\open3d_alignment `
  --voxel-size 0.015
```

配准用于把扫描点云变换到模板/CAD 坐标，不是去工装平面。典型顺序是：

```text
去工装/聚类/选目标 → 目标点云配准到模板 → 测量或深度异常检测
```

## 5. PatchCore-3D 演示

```powershell
python -m industrial_pc3d.cli deep-demo `
  --config configs\patchcore3d.json `
  --output outputs\deep_demo `
  --epochs 6
```

训练数据只有正常工件；测试集包含正常、凹坑和凸包。命令会：

1. 训练局部几何编码器；
2. 从正常点云提取局部块描述；
3. 用 farthest coreset 压缩记忆库；
4. 在正常验证集上标定点级和物体级阈值；
5. 输出异常图与评估 JSON。

输出：

| 文件 | 含义 |
|---|---|
| `patchcore3d.pt` | 编码器权重、记忆库、阈值和配置 |
| `evaluation_summary.json` | 物体准确率、召回、正常误报率、点级 AUROC |
| `anomaly_preview.png` | 最强异常测试样本的点级分数 |

常用参数：

| 参数 | 影响 |
|---|---|
| `voxel_size` | 减小会增加局部块数量与计算量 |
| `patch_k` | 局部块邻点数；应覆盖要检测的缺陷尺度 |
| `latent_dim` | 学习描述维度 |
| `epochs` | 自监督编码器轮数 |
| `memory_size` | 记忆库上限；越大覆盖越全、内存越高 |
| `calibration_quantile` | 点级阈值标定分位 |

## 6. 从合成迁移到真实产线

建议按以下顺序迁移：

1. 采集同一工位的正常、边界和已知失效样本，保留原始扫描、时间、机型、参数和操作员。
2. 建立标定文件版本和坐标系约定；先验证 ROI、平面方向和模板配准。
3. 将本项目的 `process` 输出与现场工装、工件尺寸和位置核对。
4. 在独立正常验证集上固定阈值，不查看最终测试集反复调参。
5. 先做离线批次回放，再做旁路在线运行，再做停线门控。
6. 建立漂移监控：点密度、离群率、配准 fitness、异常分数分布和置信度。
7. 发生漏检时先归因于成像、缺失点、标定、配准还是模型；不要直接用更多网络层掩盖数据问题。

Deep 演示的训练/测试拆分规则不能被当作现场拆分模板。真实项目应按工件、批次或时间切分，防止相邻扫描泄漏。

深度模型读取真实数据的 Python 入口、图像语义和为什么去平面后工件外形变化，见
[库后端与代码流程说明](库后端与代码流程说明.md)。

## 7. 排错

### `No valid workpiece cluster found`

- ROI 可能过大，背景点主导聚类。
- 去噪过强，工件被清空。
- `cluster_eps` 太小，工件被切成碎片。

### 选错工件

- 检查 `target_xy` 是否与数据库/相机坐标一致。
- 检查最大簇策略是否被工装残点主导。
- 先验证 RANSAC 平面法向和位置，再调聚类。

### RANSAC 移除工件而不是工装

- 检查平面内点率、法向和位置。
- 增加法向/高度约束，或先裁剪已知工装区域。
- 不要只调大迭代次数。

### OBB 轴不稳定

- 对称物体缺乏唯一主轴。
- 改用参考平面+参考孔/特征定义的坐标系。
- 对关键尺寸使用 CAD 配准，不只依赖 PCA-OBB。

### 深度模型显存/内存过大

- 先增大 `voxel_size`，减少每件点数。
- 降低 `max_patches_per_cloud` 和 `memory_size`。
- 大场景改用分块 + RandLA-Net/KPConv 类方法。

### 深度演示结果波动

- 合成噪声、采样和训练顺序固定时结果应基本可复现。
- 调 `epochs`、`patch_k`、`memory_size` 后再比较点级 AUROC 和固定误报率下的漏检。
- 不要只看物体级准确率；样本数少时一个正常件误报就会显著改变指标。
