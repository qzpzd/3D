# 工业 3D 点云方法与应用

## 1. 先确定任务，再选模型

工业点云项目通常落在四类任务上：

| 任务 | 主要输出 | 优先方案 | 深度模型的角色 |
|---|---|---|---|
| 定位/抓取 | 6D 位姿、目标簇 | 分割、FPFH + RANSAC + ICP、CAD 配准 | 学习局部对应、类别分割、位姿回归 |
| 尺寸/形位测量 | 距离、角度、平面度、孔位、偏差热图 | 标定、模板/CAD 配准、几何拟合、不确定度分析 | 辅助目标分割或特征找点 |
| 表面缺陷 | 工件级 OK/NG、点级缺陷图 | 规则阈值、模板距离、无监督 PatchCore 类方法 | 特征提取、记忆库、监督分割 |
| 大场景检测 | 类别、实例、缺陷区域 | 分块、下采样、聚类/分割 | PointNet++、RandLA-Net、KPConv 等 |

2025 年的工业点云综述把位姿估计、缺陷检测、测量与估计归纳为三类核心应用，并指出实时性、产品专用性、数据集和缺陷样本不足是共同约束。[1] 因此工业落地最常见的是“几何链路 + 学习组件”的混合系统，而不是把全部点云直接送进一个端到端网络。

## 2. 为什么采用这条流水线

```text
原始点云
→ 粗 ROI
→ 体素下采样
→ 噪声去除
→ 大基准平面 RANSAC
→ 工件聚类
→ 法线与边缘
→ OBB/AABB 裁剪
→ 配准或检测
```

每一步都在缩小搜索空间和降低后续模型的不确定性：

1. **ROI 只保留已知观察区**。先砍掉远背景、机器人、料框和无关相机区域。单位、相机坐标系和 ROI 边界要来自标定，而不是手工试出来。
2. **体素下采样控制密度与节拍**。每个占用体素生成一个代表点。体素过大丢失细划痕，过小让配准、聚类和深度网络的内存/时间不可控。[2]
3. **统计或半径去噪处理孤立浮点**。统计滤波按邻域平均距离阈值删除稀疏点；半径滤波要求指定半径内至少有一定邻居。高反光金属、吸收材料和遮挡会造成局部密度差，应优先分区域调参。
4. **RANSAC 先分离最大基准面**。工业工装和平台通常提供强平面支撑，Open3D 的 `segment_plane` 也采用距离阈值、采样点数和迭代次数控制平面拟合。[2] 最大平面通常不是工件，但“最大”这一先验必须通过法向、位置和支撑比例校验。
5. **DBSCAN 将工件分离**。`eps` 与 `min_points` 分别表达邻域尺度和最低密度。稠密铜件、稀疏黑色塑料件和远距离点云不能共用一套参数；过大的 `eps` 会把相邻工件粘连。
6. **法线/边缘给出局部几何状态**。PCA 协方差最小特征值方向给出法线；`λ0/(λ0+λ1+λ2)` 可作为表面变化量，切平面邻域的最大角间隙可用于边界检测。它们既可用于边缘点提取，也可用于 PatchCore 的几何描述。
7. **OBB/AABB 裁剪锁定目标工件**。PCA-OBB 适合快速去除聚类误差造成的离群点，AABB 便于与轴对齐夹具、机器人坐标和简单尺寸规则交互。严格最小体积 OBB、CAD 包围盒或客户定义的基准框需单独验证。

### 2.1 现成库与项目实现的关系

工业项目通常调用 Open3D/PCL 的成熟实现，而不是重新实现 RANSAC、KDTree 和 ICP。本项目提供三种可替换后端：

- NumPy/SciPy/scikit-learn 基线：暴露算法结构，但不应作为百万点产线核心。
- Open3D：Python 侧优先选择，覆盖 I/O、滤波、RANSAC、DBSCAN、法线、OBB、FPFH 和 ICP。
- PCL：C++ 侧选择，适合大点云、模块化算法和现有 C++ 系统。

本项目“自研”的只是薄流水线和部分参考算法，RANSAC、DBSCAN、PCA、FPFH、ICP 本身都是标准方法。详细对照、安装和命令见
[库后端与代码流程说明](库后端与代码流程说明.md)。

## 3. 传统方法及其工程取舍

### 3.1 ROI、下采样和去噪

直通滤波（PassThrough）不是几何感知滤波器，具有成本低、可解释、易于追溯的优点。它适合“相机相对工位固定”的场景；相机/机器人位姿变化时，应先做手眼变换和工件粗定位。

体素下采样会平均一个体素内的点，对全局统计量仍存在局部量化误差。高精度尺寸测量不应只在降采样云上给出毫米级结论；通常在高分辨云上测量，在低分辨云上做定位和异常粗筛。

SOR 和半径滤波处理“点是否孤立”，不处理“局部形状是否正确”。表面划伤、凹陷和薄壁缺失往往仍具有足够邻点，需要模板距离或异常模型。

### 3.2 RANSAC、聚类和裁剪

RANSAC 对离群点容忍度较高，但存在三个常见失效模式：

- 工件大面积平面比夹具更大，算法移除的是工件而不是工装。
- 多个工装面近似共面，最大平面中混入底部工件点。
- 距离阈值过大，将薄工件整体当作平面。

工程中应增加平面方向约束、位置约束、法向与预期工装法向夹角约束，并记录内点率和平面参数。只保留“点数最多”的平面不足以构成可靠工装识别。

DBSCAN 不需要事先指定簇数量，适合单工位多工件。但参数依赖点密度，且没有按任务类别筛选工件的能力。量产通常会在聚类后增加尺寸、位置、体积、颜色或分类器门控。

PCA-OBB 的轴由最大方差方向给出，计算快、可重复，但当目标接近球形、强对称或局部遮挡时，主轴符号和顺序可能翻转。若下游依赖固定轴顺序，应使用模板配准后的坐标框或定义参考平面/参考孔。

### 3.3 配准

Open3D 文档中的经典配准链路是：

1. 下采样、估计法线、计算 FPFH；
2. 用特征匹配和 RANSAC 做粗配准；
3. 以粗变换初始化，用 point-to-plane ICP 精配准；
4. 用 `fitness` 与 `inlier_rmse` 判断重合比例和几何误差。[3][4]

本项目的无 Open3D 版本实现了 FPFH 风格 33 维局部描述、互近邻特征对应、RANSAC Kabsch 和点到点 ICP，便于理解与移植。生产版的优先事项是初始位姿、点法线质量和距离阈值，而不是盲目增加 RANSAC 迭代次数。

对于强对称工件，应使用非对称特征、完整部位置信度或学习式对应模型来消除多解。配准分数高不等于合格：如果扫描与一个有缺陷的模板都对齐，后续距离图仍可能把缺陷压掉。

配准在流程中的位置如下：

```text
传统测量：原始场景 → 去工装 → 聚类 → 目标工件 → 模板/CAD 配准 → 测量
深度检测：原始场景 → 去工装 → 聚类 → 目标工件 → 模板配准 → PatchCore/分割
```

它把点云变换到统一坐标，不改变工件尺寸。未配准时，同一工件旋转会造成模板距离和局部异常分数误报。当前合成 PatchCore 演示使用标准姿态，所以没有显式执行配准；真实数据应先配准。

## 4. 深度 3D 方法地图

### 4.1 分类和点级分割

PointNet 直接处理无序点集并聚合逐点特征；PointNet++ 在其上加入尺度化的邻域采样、局部聚合和层级抽象，专门缓解 PointNet 对局部结构表达不足以及点密度变化的问题。[5]

常见工业选择：

- **PointNet/PointNet++**：数据规模中小、类别或缺陷类型明确、需要快速搭建基线和消融。
- **DGCNN**：在局部动态图上做 EdgeConv，强调邻接关系；工业综述总结中也有将 DGCNN 用于缺陷分割的案例。[1]
- **RandLA-Net**：随机采样和局部特征聚合面向大场景；原论文报告可单次处理百万点，并显著降低相较复杂采样方法的耗时。[6]
- **KPConv**：连续空间核卷积，适合注重几何细节的中大型点云，但计算和工程复杂度更高。

选择顺序应是“先确认传感器分辨率、缺陷最小尺度、标签一致性和节拍”，再比较网络。一个能从 1 mm 间距点云中识别划痕的模型，不会因为换成更大的网络就自动适应 5 mm 间距。

### 4.2 无监督异常检测

PatchCore 的核心思想是只用正常样本建立局部特征记忆库，在测试时以到记忆库的最近邻距离作为异常分数；coreset 用于减少冗余特征和推理成本。[7]

3D 工业异常基准说明了几个现实问题：

- MVTec 3D-AD 提供 10 类工业对象的 3D 扫描，训练和验证只含正常样本，测试含划痕、凹坑、孔洞、污染和变形等缺陷。[8]
- Real3D-AD 面向高精度完整点云，报告约 1,254 件样本、每件 4 万到数百万点，并测试 PatchCore+FPFH、Point-MAE、Point-BERT 等组合。[9]
- Real3D-AD 同时指出训练、计算和存储会迫使研究基线下采样，而边缘截断等扫描问题仍会诱发误检。[9]

因此 3D PatchCore 的关键不是名字，而是以下因素：

1. 正常训练样本覆盖姿态、表面、批次和传感器漂移。
2. 点云在比较前完成标定、工装移除和模板/位姿对齐。
3. 局部块的尺度对应最小缺陷尺度，且记忆库有代表性。
4. 异常图能从块级可靠映射回点级，并处理“缺失点”缺陷。
5. 阈值使用独立验证集标定，并以产线单位长度上的误报率监控。

本项目的 `PatchCore3D` 是教学基线：局部几何编码器只在正常块上训练，记忆库使用 farthest coreset，测试分数为局部记忆距离。它保留了 PatchCore 的“正常记忆库 + 局部异常”思想，但没有使用 ImageNet/Point-MAE 预训练主干，因此不能直接引用 2D 或 Real3D-AD 的论文成绩。

### 4.3 学习式配准和位姿

传统 FPFH-RANSAC-ICP 仍是可解释的强基线，尤其在 CAD 模板、结构纹理和稳定局部特征存在时。学习式配准更适合：

- 重复纹理、弱几何或无纹理表面导致传统描述子歧义；
- 遮挡和离群点比例高；
- 需要一次预测多个对应或端到端位姿；
- 场景分布稳定但传统参数难以覆盖。

生产系统通常仍保留几何一致性检查、ICP 精化和配准失败拒识。网络输出位姿不能绕过坐标系、手眼标定和误差传播。

## 5. 推荐工业组合

| 场景 | 第一版 | 后续升级条件 |
|---|---|---|
| 固定工位、单一外形、尺寸检测 | ROI + 平面移除 + 模板配准 + 点面/距离/尺寸规则 | 数据证明规则召回不足后再加入学习特征 |
| 多工件随机摆放 | 聚类 + 目标分类/分割 + 配准 + 模板比较 | 有足够边界框/掩码后训练 PointNet++ 或实例分割 |
| 无缺陷样本、缺陷种类未知 | 对齐后的 PatchCore/FPFH 基线 + 多视角异常图 | 收集真实 NG，做独立阈值和误检归因 |
| 明确缺陷类别、标注充足 | PointNet++/DGCNN/RandLA-Net 监督分割 | 若大场景，再评估 RandLA-Net/KPConv 的显存和节拍 |
| 高反光、点缺失、视角遮挡 | 多传感器/多视角、几何有效性掩码、缺失点检测 | 单模型无法恢复传感器未采集到的表面 |

## 6. 数据集与实验设计

不要按相邻扫描帧随机划分训练/验证/测试。高相关帧落入两侧会造成严重数据泄漏。至少按工件、批次或采集时段划分；更严格的量产验证要跨设备、跨班次。

推荐报告：

- 传统阶段：各步骤保留点数、耗时、平面内点率、簇数量、目标误选率。
- 异常检测：物体 AUROC/AUPR、点级 AUROC/AUPR、给定 FPR 下漏检率、每千件误报数。
- 测量：重复性、偏差、线性、与三坐标/量具的一致性、Gage R&R 或客户要求的不确定度。
- 性能：预处理、网络、后处理各自 P50/P99 延迟，以及峰值显存/内存。
- 鲁棒性：点密度、离群点率、平面倾角、遮挡、温度、环境光和夹具磨损分层结果。

公开基准可以用于方法筛选，但不能作为验收数据。MVTec 3D-AD 和 Real3D-AD 的价值在于任务定义、正常/异常划分和可比较指标，而不是替代现场工件。

## 7. 容易忽视的失效模式

- **单位错误**：CAD 为毫米而扫描为米，阈值全部失效。
- **标定漂移**：手眼矩阵、温漂或镜头变化会让模板距离整体偏置。
- **错误去平面**：最大平面不一定是工装；工件平面也可能被移除。
- **密度不一致**：近处与远处点间距不同，固定 `eps` 和固定邻域点数会造成偏差。
- **点缺失**：3D 异常模型只能评分“存在的点”，孔洞和遮挡造成的缺失需用 2D 映射、网格化或有效掩码检测。
- **对称多解**：长方体、圆轴和回转体具备多组近似正确位姿，必须定义参考特征。
- **过拟合正常样本**：正常样本过少时，微小环境变化就可能被当成异常。
- **阈值泄漏**：反复在最终测试集调阈值会高估上线表现。
- **合成到真实差距**：合成缺陷验证的是代码路径，不是光学、反光和传感器噪声的泛化能力。
